# Requirements Matrix

Source: `Especificacion_Tecnica_Consolidada_v1_4_FINAL.docx`, v1.4 FINAL (September 2026), primarily section 14 (`CP01`-`CP70`), with model, UI, permissions, API, KPI, and phase references from sections 2, 5-11, 15, and 23.

## Status Legend

| Status | Meaning |
|---|---|
| `IMPLEMENTED (F0)` | Direct F0 foundation is implemented and exercised by F0 tests. This does not claim execution of a later-phase CP acceptance test. Production master data remains intentionally unseeded until Excel import. |
| `STRUCTURALLY COVERED (F0); acceptance PLANNED (Fx)` | F0 provides and tests a necessary data/contract foundation, but the CP needs a future operational module before its executable acceptance behavior can be tested. |
| `PLANNED (Fx)` | Later-phase work with no completed F0 foundation claimed. Its acceptance behavior is not marked implemented or executed. |

The status is a roadmap classification from section 11, not evidence that an acceptance test has been executed. A dash (`—`) means the specification does not assign an item in that column.
